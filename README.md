# Discussion Board Web Application

## Overview
The Discussion Board is a web-based application designed to enable users to ask questions, share knowledge, and participate in online discussions. The project demonstrates fundamental full-stack web development concepts, including user authentication, database integration, form handling, and organized project structure.

## Key Features
- **User Authentication:** User registration and login functionality.
- **Post Questions:** Allow users to create and publish questions.
- **Answer Questions:** Enable users to respond to questions and share knowledge.
- **Like Questions:** Support user interaction through likes.
- **Related Discussions:** Display related questions to improve content discovery.
- **Database Integration:** Store and manage user and discussion data using MySQL.
- **Responsive UI:** Use Bootstrap to create a clean, user-friendly interface.

## Technologies Used
- **PHP** — Server-side programming and request handling.
- **MySQL** — Database storage and management.
- **HTML5** — Web page structure.
- **CSS3** — Styling and layout.
- **Bootstrap** — Responsive user interface.
- **XAMPP** — Local development environment.
- **phpMyAdmin** — Database administration.
- **Visual Studio Code** — Code editing and development.
- **Git and GitHub** — Version control and project hosting.

## Learning Objectives
This project focuses on understanding PHP application structure, MySQL database configuration, user authentication, form submission, database operations, session management, and integrating frontend components with backend functionality.

## Local Setup
1. Install XAMPP and start Apache and MySQL.
2. Place the project folder inside the XAMPP `htdocs` directory.
3. Create the required MySQL database using phpMyAdmin.
4. Configure the database connection in the project configuration file.
5. Import the database SQL file if one is provided.
6. Open the project in your browser using `http://localhost/your-project-folder/`.

## Project Purpose
This project is developed for practical learning and to strengthen skills in PHP development, relational databases, and dynamic web application development.
